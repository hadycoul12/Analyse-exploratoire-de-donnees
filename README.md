# Analyse exploratoire de données avec Python

Notebook pédagogique qui déroule une analyse exploratoire (EDA) complète : de la description d'une variable à la lecture d'une structure multivariée.

## Contenu

| Fichier | Rôle |
|---|---|
| `EDA_Python.ipynb` | Analyse univariée (variables numériques et catégorielles), bivariée et multivariée |
| `Introduction Python pour EDA/Into_Python_EDA.ipynb` | Prise en main de Python (variables, boucles, fonctions) par un exercice ludique |

## Démarche

1. **Analyse univariée** : distribution, valeurs extrêmes, modalités.
2. **Analyse bivariée** : liens entre variables, corrélations, tests.
3. **Analyse multivariée** : lecture d'ensemble des relations entre variables.

## Outils

Python, pandas, NumPy, SciPy, Matplotlib, Seaborn, Plotly.

## Lancer le notebook

```bash
pip install pandas numpy scipy matplotlib seaborn plotly jupyter
jupyter notebook EDA_Python.ipynb
```
